# 🎬 Movie Ticket Booking System

A console-based **Movie Ticket Booking System developed in C++** using Object-Oriented Programming (OOP) concepts. The system allows users to view movies and shows, select seats, book tickets, make payments, cancel bookings, and view their booked tickets.

## ✨ Features

- 🎥 View available movies
- 🕐 View available shows and screens
- 💺 Display seat layout and availability
- 🎟️ Book multiple seats
- 💰 Automatic ticket price calculation based on seat type
- 💳 Multiple payment methods:
  - UPI
  - Card
  - Cash
- ✅ Payment success/failure simulation
- ❌ Cancel confirmed bookings
- 🔄 Automatically release cancelled seats
- 🎫 Generate and display ticket details
- 🔢 Unique booking ID generation
- ⚠️ Input validation for invalid and duplicate seats

## 🛠️ Technologies Used

- **C++**
- **Object-Oriented Programming**
- Standard Template Library (STL)
- Vectors
- Classes & Objects
- Inheritance
- Polymorphism
- Encapsulation
- Static Members

## 📂 Project Structure

The project is divided into multiple C++ files, with separate classes for:

- Movie
- Seat
- Screen
- Cinema
- Show
- ShowSeat
- Customer
- Booking
- Payment
- Payment Types
- Price Calculator
- Ticket Printer
- Booking Service

## ▶️ How to Run

Compile the project using:

```bash
g++ main.cpp -o movie.exe

```

Run the program:

```bash
./movie.exe

```

> **Note:** Compile only `main.cpp` because it includes the other project files.

## 🎯 Purpose

This project was developed as an academic project to demonstrate practical implementation of **OOP concepts, modular programming, inheritance, polymorphism, and basic booking-system functionality in C++**.
